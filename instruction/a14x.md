### Before start flashing

- Always have backup of your internal storage
- Use Official TWRP or ROM specific Recovery
- Download latest stock firmware

### Flashing Guide
- Flash stock firmware in download mode
- Flash recovery
- Format data
- Wipe Dalvik/Art Cache,cache
- Reboot to recovery
- Flash the ROM
- Flash the Nikgapps/MindTheGapps (Note: Flash if you need Google apps)
- Tap on format data, type yes and reboot to system
