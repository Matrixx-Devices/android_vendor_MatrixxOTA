**Before start flashing.....**
- Always have backup of your internal storage

----

**Clean flash:**
- Download the ROM
- Boot into recovery (If you want Matrixx Recovery [**Click Here**](https://get.projectmatrixx.org/folder/munch/12.x/12.2/Matrixx_recovery_12.2.zip)
- Wipe Dalvik/Art Cache, cache and data
- Flash the ROM and reboot to recovery
- Tap on format data, type yes and reboot to system

**Dirty flash:**
- Download the ROM
- Boot into recovery
- Flash the ROM.zip
- Wipe Dalvik/ArtCache
- Reboot To System
