**Before start flashing.....**
- Always have backup of your internal storage
- Use recommended recovery
- Both vanilla and gapps builds are available

----

**Clean flash:**
- Download the ROM
- Boot into custom recovery
- Wipe Dalvik/Art Cache, cache, data and metadata
- Use Flash current recovery option to keep custom recovery
- Flash the ROM and reboot to recovery
- Flash gapps if flashed vanilla build
- Tap on format data, type yes and reboot to system

**Dirty flash:**
- Download the ROM
- Boot into recovery
- Flash the ROM.zip
- Wipe Dalvik/ArtCache
- Reboot To System
