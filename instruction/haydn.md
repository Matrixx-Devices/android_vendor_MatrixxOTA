## Flashing Guide for Haydn A12/13/14/15 ROMs 

## Clean Flash:
- Download and boot into Ofox/TWRP image using 
`fastboot boot recovery.img` **OR** `fastboot boot twrp-3.7.1_12-v9.0_A15-haydn-skkk.img`
- Wipe Data, Metadata, Cache, Dalvik-Cache
- Copy ROM to Internal Storage and Flash ROM & Recovery **OR** Sideload ROM
- Reboot Recovery (Not Needed if using TWRP A15 (Skkk 9.0) you can directly format data)
- Format Data 
- Reboot System

## Dirty Flash:
- Reboot Recovery 
- Flash ROM & Recovery 
- Reboot System 

## Note:
- After flashing the ROM it might show some errors but it's fine
- TWRP doesn't have a flashable zip, just go to advanced then tap on flash current TWRP
